# My ePortfolio

## How to use
1. Extract this ZIP file.
2. Open the `my-eportfolio` folder in VS Code.
3. Open `index.html` in your browser or use the Live Server extension.
4. Edit the text with your own information.
5. Upload the files to a GitHub repository.
6. Enable GitHub Pages in the repository Settings > Pages.

## Files
- `index.html` - Website content
- `style.css` - Website design
- `script.js` - JavaScript
- `images/` - Put your pictures here
